# Команда ИИ-агентов для тестового O-complex

Набор для Claude Code: правила проекта, 8 ролей-субагентов и промпты для запуска.

## Что внутри

```
CLAUDE.md                   ← общие правила проекта, Claude Code читает его всегда
.claude/agents/             ← роли команды (субагенты)
  kb-builder.md             — база знаний и матрица допродаж
  prompt-engineer.md        — системный промпт, схема, тестовые обращения
  backend-dev.md            — API, retrieval, LLM-слой
  amocrm-integrator.md      — вебхук и примечания в amoCRM
  frontend-dev.md           — демо-интерфейс
  qa-evaluator.md           — прогон тестов и отчёт о качестве
  demo-producer.md          — сценарий видео и рассказ об ИИ-инструментах
  interview-coach.md        — подготовка к вопросам по решению
prompts/
  00-bootstrap.md           — волна 0: каркас и контракты (последовательно)
  01-wave-parallel.md       — волна 1: параллельная работа
  02-wave-integration.md    — волна 2: сборка и качество
  03-wave-delivery.md       — волна 3: видео и подготовка к интервью
```

## Как запускать

1. Создайте пустую папку, скопируйте туда содержимое архива, выполните `git init`.
2. Запустите `claude` в этой папке.
3. Идите **строго по волнам**. Внутри волны агенты работают параллельно, между волнами нужна синхронизация.

```
Волна 0 (последовательно)  ─ каркас + контракты (схема ответа, формат базы)
        │
Волна 1 (параллельно)      ─ kb-builder │ prompt-engineer │ backend-dev │ amocrm-integrator │ frontend-dev
        │
Волна 2 (последовательно)  ─ сборка → qa-evaluator → исправления
        │
Волна 3 (параллельно)      ─ demo-producer │ interview-coach
```

**Почему волна 0 обязательна.** Параллельные агенты не видят работу друг друга. Если не зафиксировать заранее схему ответа и формат базы знаний, каждый придумает свою версию и на сборке всё развалится. Контракты — это то, что позволяет работать параллельно.

## Два способа параллельности

- **Проще:** одна сессия Claude Code, промпт волны просит запустить несколько субагентов одновременно. Подходит для большинства задач.
- **Мощнее:** несколько терминалов, у каждого свой git worktree (команды есть в `prompts/01-wave-parallel.md`). Каждый агент работает в своей ветке, потом ветки сливаются. Нужно, если агенты правят много файлов.

## Ваша роль

Вы тимлид, а не зритель. После каждой волны:
- просмотрите изменения (`git diff`), не принимайте вслепую;
- дополняйте `docs/ai-log.md` своими наблюдениями: где ИИ ошибся и как вы это поймали. Это основа рассказа в видео и на интервью.
