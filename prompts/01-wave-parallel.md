# Волна 1 — параллельная работа 5 агентов

Перед запуском: волна 0 закоммичена, в `.env.local` лежат ключи API модели (и, если уже есть, amoCRM).

## Вариант А (рекомендуется): одна сессия, параллельные субагенты

Скопируйте текст ниже в Claude Code:

---

Ты тимлид. Каркас и контракты готовы (см. `CLAUDE.md`, `src/lib/contracts.ts`, `data/kb/README.md`). Запусти **одновременно, в одном сообщении**, пять субагентов, каждого со своей задачей из его описания в `.claude/agents/`:

1. `kb-builder`: собрать базу знаний O-complex и матрицу допродаж.
2. `prompt-engineer`: системный промпт, few-shot, eval-набор `data/eval/cases.json`.
3. `backend-dev`: retrieval, LLM-слой, `/api/assist`, логирование токенов. Пока базы нет, использовать примеры из `data/kb/`.
4. `amocrm-integrator`: исследование API amoCRM, клиент, вебхук, mock-режим.
5. `frontend-dev`: демо-интерфейс на мок-ответе.

Каждому агенту в задаче явно напомни:
- работать только в своей зоне файлов;
- контракт не менять, предложения писать в `docs/contract-changes.md`;
- в конце сделать запись в `docs/ai-log.md` и коммит `<роль>: ...`;
- вернуть тебе отчёт: что сделано, что не получилось, какие допущения, какие файлы изменены.

Когда все закончат:
1. Сведи их отчёты в таблицу (агент / статус / допущения / риски).
2. Проверь `docs/contract-changes.md`: если есть предложения, покажи их мне и **не применяй без моего ОК**.
3. Запусти `npm run typecheck && npm run lint` и перечисли конфликты или ошибки.
4. Предложи, что поправить до волны 2.

## Вариант Б: несколько терминалов через git worktree

Нужен, если агенты начинают править общие файлы или хочется видеть каждый процесс отдельно.

```bash
# из корня проекта, после коммита волны 0
git worktree add ../oc-kb       -b feat/kb
git worktree add ../oc-prompt   -b feat/prompt
git worktree add ../oc-backend  -b feat/backend
git worktree add ../oc-amocrm   -b feat/amocrm
git worktree add ../oc-frontend -b feat/frontend

# скопируйте .env.local в каждую папку
for d in kb prompt backend amocrm frontend; do cp .env.local ../oc-$d/; done
```

В каждом терминале: `cd ../oc-<роль> && claude`, затем промпт:

```
Действуй как субагент <роль> из .claude/agents/<роль>.md. Выполни его задачу полностью.
Работай только в своей зоне файлов. В конце запись в docs/ai-log.md и коммит.
```

После завершения, в основной папке:

```
Слей ветки feat/kb, feat/prompt, feat/backend, feat/amocrm, feat/frontend в main по одной.
При конфликтах в docs/ai-log.md объединяй записи, ничего не теряя.
При конфликтах в коде остановись и покажи мне конфликт с твоим предложением решения.
После слияния: npm install, typecheck, lint, и отчёт.
```

Удаление worktree после слияния: `git worktree remove ../oc-<роль>`.
