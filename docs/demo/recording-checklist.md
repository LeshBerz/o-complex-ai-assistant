# Чек-лист записи видео

## За день до записи

- [ ] Дневной лимит OpenRouter (50 запросов) не исчерпан: на запись нужно 1–2 запроса (mock-вебхук amoCRM и, по желанию, один прогон prompt injection в «API»). Лимит сбрасывается раз в сутки, точное время сброса: `[ЗАПОЛНИТЬ]`.
- [ ] `npm run build-index` выполнен, `data/kb/index.json` свежий.
- [ ] `npm run typecheck` и `npm run lint` зелёные, дерево git чистое: в кадре может мелькнуть терминал.
- [ ] Репозиторий https://github.com/LeshBerz/o-complex-ai-assistant открывается без входа в аккаунт (проверить в режиме инкогнито).

## Экран и браузер

- [ ] Запись 1920×1080, 30 fps. Окно браузера ровно 1280×720 или во весь экран: экскурсия проверена на 1280×720 (`docs/ai-log.md`, frontend-dev).
- [ ] Масштаб браузера 100%. Если текст «Под капотом» мелкий для видео, попробовать 110–125%, затем пройти экскурсию целиком и проверить, что поповеры не обрезаются.
- [ ] Отдельный профиль браузера без расширений, закладок и чужих вкладок. Панель закладок скрыта.
- [ ] Уведомления Windows и мессенджеров выключены (режим «Не беспокоить»).
- [ ] Курсор крупнее обычного или с подсветкой клика (по желанию).
- [ ] В терминале крупный шрифт (16–18 pt), тёмная тема, очищенная история. На экране **нет** `.env.local` и ключей.

## Прогрев сервиса

- [ ] Сервер запущен с прокси, иначе запросы к модели получат 403: `node --use-env-proxy node_modules/next/dist/bin/next dev -p 3000` (конфигурация `dev` в `.claude/launch.json`).
- [ ] Страница один раз открыта и экскурсия пройдена целиком до записи: первая компиляция маршрутов в `next dev` медленная, первая загрузка модели эмбеддингов ≈ 16 с (`docs/decisions.md`).
- [ ] Перед дублем страница перезагружена с `?tour=1`: экскурсия стартует с шага 1, режим «Мок», сценарий сброшен.

## Заготовленные сценарии (всё в «Моке», экскурсия ведёт сама)

- [ ] Шаг 3: «Повторный покупатель» → ответ с меткой «Заказ» и допродажей upsell-015 (минеральная бутылка).
- [ ] Шаг 10: «Беременность (противопоказания)» → жёлтая плашка «Нужен менеджер», допродажа отключена.
- [ ] Сценарий «Попытка prompt injection» в «Моке» **не показывать**: в моке у него причина «Вопрос о здоровье», и это неверно. Либо сказать словами, либо заранее записать один ответ в режиме «API» и вклеить (подробности в `script.md`).
- [ ] Сценарий «Жалоба» в «Моке» тоже не показывать: та же причина «Вопрос о здоровье».

## amoCRM (mock-режим)

- [ ] В `.env.local` есть `AMOCRM_MODE=mock` и `AMOCRM_WEBHOOK_SECRET` (сейчас оба заданы).
- [ ] Перед записью удалить `logs/amocrm-*.jsonl` и перезапустить сервер: повтор того же сообщения отсекается как дубль, пока жив процесс.
- [ ] Во втором терминале: `npx tsx scripts/amocrm-mock-webhook.ts message-add`. Ожидается `← 200 за … мс`, затем примечание в `logs/amocrm-notes.jsonl` и в консоли `next dev`.
- [ ] Помнить: amoCRM здесь подменён фикстурами, а **модель вызывается настоящая** (1 запрос, 10–30 с). Записать этот кусок отдельно, ожидание вырезать.
- [ ] Окна консоли `next dev` и скрипта стоят рядом, текст примечания (🤖 / 💡 / ⚠️) виден целиком.
- [ ] Запасной вариант, если лимит модели кончился: показать раздел «Демо в mock-режиме» в `docs/amocrm-setup.md` и честно сказать, что примечание пишется в лог. Не выдавать это за живую сделку.

## Звук

- [ ] Тихая комната, окна закрыты, уведомления телефона выключены.
- [ ] Внешний или гарнитурный микрофон, не встроенный в ноутбук. Расстояние 15–20 см, сбоку от рта.
- [ ] Тестовая запись 10 с: нет эха, гула и щелчков клавиатуры. Уровень голоса около −12 dB.
- [ ] Закадр прочитан вслух с секундомером: укладывается в 1:55–2:00 (см. подсчёт в `script.md`). Если нет, убрать фразы с ✂.
- [ ] Вариант на случай нервов: записать экран без звука, а голос отдельно и свести при монтаже.

## После записи

- [ ] Длительность не больше 2:00.
- [ ] В кадре нет ключей, токенов, личных вкладок и почты.
- [ ] Цифры в кадре совпадают с закадром (таблица «Откуда цифры в закадре» в `script.md`).
- [ ] Ссылка на видео открывается без входа в аккаунт. Вставить её в `docs/demo/message.md` вместо `[ССЫЛКА НА ВИДЕО]`.
