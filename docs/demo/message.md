Под вакансию «разработчик по вайбкодингу и ИИ-интеграциям» (`docs/vacancy.md`). Для почты или hh.ru, 7 предложений.

---

Здравствуйте! Отправляю тестовое задание: ИИ-ассистент менеджера O-complex. На обращение клиента он готовит вежливый черновик ответа по базе знаний и подсказку по допродаже, а вопросы о здоровье, жалобы и всё, чего нет в базе, передаёт менеджеру. База собрана с o-complex.com (RAG), интеграция с amoCRM работает через вебхук: подсказка приходит примечанием в сделку. Пока это проверено в mock-режиме на фикстурах из документации, без живого аккаунта. Весь проект собран в Claude Code командой ИИ-агентов, я выступал тимлидом и проверял результат: качество меряю eval-набором из 20 обращений, а каждую ошибку ИИ записываю в журнал, например, как разбор ответов в eval-прогоне показал, что модель переносит выдуманные факты из учебных примеров в реальные ответы. Видео на 2 минуты: [ССЫЛКА НА ВИДЕО], код и отчёты: https://github.com/LeshBerz/o-complex-ai-assistant.
