# Архитектурные решения

## 2026-09-30 — стек (волна 0)

| Слой | Выбор | Версия | Почему |
|---|---|---|---|
| Язык | TypeScript strict | 5.x (из шаблона Next) | Одни типы на фронте, бэке и в контрактах; zod-схемы дают и типы, и валидацию в рантайме |
| Рантайм | Node.js LTS | 22.x | Актуальная LTS на машине |
| Фреймворк | Next.js App Router | 16.3.7 | UI и API в одном проекте, деплой на Vercel в один клик — для демо самый короткий путь |
| LLM-слой | Vercel AI SDK `ai` | 7.x | `generateObject` + zod-схема: структурированный ответ без ручного парсинга JSON, провайдер меняется через env |
| Провайдер | `@ai-sdk/openai` | 4.x | Один ключ на генерацию и эмбеддинги (у Anthropic нет API эмбеддингов) |
| Валидация | zod | 4.x | Контракт в одном месте (`src/lib/contracts.ts`) |
| Поиск | эмбеддинги API + cosine в памяти | — | База маленькая (десятки чанков): векторная БД избыточна; индекс — json-файл |
| UI | React 19 + Tailwind 4 (+ shadcn/ui по необходимости) | — | Быстро собрать аккуратный демо-экран |
| CRM | amoCRM REST v4 через `fetch` | — | Нужны 3–4 эндпоинта, SDK не оправдан; есть mock-режим (`AMOCRM_MODE=mock`) для демо без доступа к аккаунту |
| Скрипты | `tsx` | 4.x | Запуск TS-скриптов (`build-index`, `eval`) без сборки |

**Примечание по версиям.** `npm view typescript version` возвращает 7.0.2, а `eslint` — 10.x. Оставил версии из шаблона `create-next-app` (TypeScript ^5, ESLint ^9): их гарантированно поддерживают `eslint-config-next` и плагин Next для TypeScript. Обновление вынесено в отдельную задачу.

## Контракты
- Запрос/ответ: `src/lib/contracts.ts`, сигнатура ядра `AssistFn`.
- Тело `POST /api/assist`: запрос `AssistRequest`, ответ `AssistResult` (`{ response, meta }`).
- Формат базы: `data/kb/README.md`. id чанков в формате `<type>:<slug>[:n]` возвращаются в `sources`.
