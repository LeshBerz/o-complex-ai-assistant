| Эмбеддинги | локально, `@huggingface/transformers` + `Xenova/multilingual-e5-small` | 4.x | Бесплатно, без ключа и лимитов, понимает русский. Проверено запуском: dim 384, первая загрузка ~16 с |
| Поиск | cosine в памяти по `index.json` | — | База маленькая (десятки чанков), векторная БД избыточна |

**Примечание по версиям.** `npm view typescript version` возвращает 7.0.2, а `eslint` — 10.x. Оставил версии из шаблона `create-next-app` (TypeScript ^5, ESLint ^9): их гарантированно поддерживают `eslint-config-next` и плагин Next для TypeScript. Обновление вынесено в отдельную задачу.

## Контракты
- Запрос/ответ: `src/lib/contracts.ts`, сигнатура ядра `AssistFn`.
- Тело `POST /api/assist`: запрос `AssistRequest`, ответ `AssistResult` (`{ response, meta }`).
- Формат базы: `data/kb/README.md`. id чанков в формате `<type>:<slug>[:n]` возвращаются в `sources`.

## 2026-09-30 — смена провайдера: OpenAI → OpenRouter + локальные эмбеддинги

**Почему не OpenAI:** бесплатных кредитов для новых аккаунтов нет с середины 2025 года, минимальное пополнение $5, а из РФ ещё нужна зарубежная карта.
**Почему не Anthropic:** тоже платно, и нет API эмбеддингов.
**Почему не Gemini:** у кандидата не создаётся ключ в AI Studio («Failed to list imported projects: permission denied»), хотя IP с VPN показывает Нидерланды. Вероятно, мешает регион, записанный в аккаунте Google.
**Почему не GitHub Models:** закрыт 30.07.2026 ([docs](https://docs.github.com/en/github-models/quickstart)). Сначала ИИ рекомендовал его по сторонним статьям и поймал ошибку только при проверке официальной документации.
**Почему не GigaChat:** бесплатно и работает из РФ, но провайдера для AI SDK нет. Нужны свой адаптер вместо `generateObject` и сертификат Минцифры. Оставлен как запасной вариант.

**Выбор:** OpenRouter (модели `:free`) + локальные эмбеддинги.
**Цена решения:**
- лимит OpenRouter 50 запросов в день (1000 после разового пополнения на $10);
- набор бесплатных моделей меняется;
- не все модели держат structured output;
- на Vercel модель эмбеддингов (~120 МБ) скачивается при холодном старте.

**Как смягчаем:**
- модель задаётся в env;
- при невалидном ответе одна повторная попытка;
- в eval кэшируем ответы, чтобы не тратить лимит;
- индекс считается заранее скриптом `build-index`.
