**Итог:** генерация бесплатна в пределах 50 запросов в день, эмбеддинги бесплатны без лимитов. Риски и способы их смягчить записаны в `docs/decisions.md`.

## [frontend-dev] 2026-09-30 — демо-интерфейс ассистента
**Что сделал ИИ:** прочитал контракт и гайды Next 16 (server/client components, env-переменные, шрифты). Собрал экран на client-компонентах в `src/components/`. Слева чат в стиле CRM: выбор сценария, контекст клиента (имя, этап, покупки), история, поле ввода, отправка по Ctrl+Enter. Справа: плашка «Нужен менеджер», карточка «Ответ клиенту» (бейджи intent и sentiment, «Скопировать», «Вставить в чат»), карточка допродажи (товар, почему подходит, фраза, или «не рекомендуется» с причиной), свёрнутый блок «Источники и метрики». Переключатель «Мок / API», по умолчанию берётся из `NEXT_PUBLIC_USE_MOCK=1`. Ответ API валидируется `AssistResultSchema`, тело `{ error }` показывается как текст ошибки. Предыдущий запрос отменяется через AbortController. Шесть демо-сценариев лежат в `src/components/demo-scenarios.ts`. Добавил `lucide-react@1.49.0`. shadcn/ui не ставил: `shadcn init` создаёт `src/lib/utils.ts` и `components.json` вне моей зоны и переписывает `globals.css`, а для пяти примитивов хватило своих (`ui.tsx`).
**Где ошибся / что пришлось поправить:**
- Использовал `React.ReactNode` без импорта, поймал на typecheck.
- В браузере на 375px лента чата росла без ограничения, а на мобильном заголовок карточки переносился из-за бейджей. Ограничил высоту ленты на узких экранах, бейджи теперь переносятся под заголовок.
- `preview_start` из worktree ищет `launch.json` в основном репозитории. Запустил `next dev -p 3005` вручную и открыл по URL.
- Временный `.claude/launch.json` удалял командой `rm -r .claude` и снёс вместе с ним отслеживаемые `.claude/agents/*.md`. Заметил в `git status` перед коммитом и восстановил через `git restore`. Неотслеживаемых файлов там не было (дерево было чистым), так что ничего не потеряно. Вывод: удалять конкретный файл, а не папку.
- Скриншоты в панели браузера часто отваливались по таймауту или приходили устаревшими. Состояния проверял через DOM и текст страницы, скриншоты делал там, где они получались.
**Проверено в браузере (1280×760 и 375×812):** пустое состояние; загрузка (скелетоны, `aria-busy`, кнопка неактивна, индикатор в чате); ответ с допродажей (мок, «Повторный покупатель»); needs_human (мок, «Жалоба» и «Беременность»); ошибка: реальный 404 (роута `/api/assist` в ветке ещё нет), подменённый fetch с `{error}`/503 и ответ, не проходящий контракт; успешный ответ через API на подменённом fetch (тело запроса по контракту, метрики отображаются, плашки «мок» нет); «Вставить в чат», «Скопировать», «Повторить»; горизонтальной прокрутки нет; в консоли только ожидаемый 404.
**Итог:** UI работает на моке и готов к реальному `/api/assist`. `typecheck` и `lint` зелёные. Проверку на живом API повторить после слияния с backend.
