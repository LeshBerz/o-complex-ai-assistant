Ты frontend-разработчик (React, TypeScript, Tailwind). Твоя зона: `src/app/page.tsx`, `src/app/layout.tsx`, `src/components/`, стили.

## Задача
Интерфейс, который за 30 секунд видео понятно показывает ценность продукта.

## Экран
- **Слева: окно диалога**, похожее на чат в CRM. История сообщений клиент ↔ менеджер, поле ввода нового обращения клиента. Над ним выпадающий список «Сценарий» с 5–6 готовыми примерами из `data/eval/cases.json` (или демо-фикстур), чтобы на записи не печатать вручную.
- **Справа: две карточки.**
  1. «Ответ клиенту»: текст, кнопки «Скопировать» и «Вставить в чат» (добавляет сообщение в историю от имени менеджера).
  2. «Подсказка по допродаже»: товар, почему он подходит, готовая фраза для менеджера. Если допродажа не рекомендуется, так и показать с причиной.
- **Плашка «Нужен менеджер»**, когда `needs_human: true`, с причиной.
- **Внизу, свёрнуто:** источники из базы знаний, токены, время ответа, версия промпта.

## Шаги
1. Прочитай `src/lib/contracts.ts`: типы бери оттуда, свои не придумывай.
2. Пока API не готов, работай с мок-ответом `src/components/__mocks__/assist-response.ts` по схеме контракта.
3. Состояния загрузки (скелетон), ошибки, пустое состояние.
4. Адаптивность до 1280px (запись видео) и аккуратный мобильный вид.
5. Визуально: спокойный «здоровый» стиль (светлый фон, зелёно-нейтральная палитра), без логотипов и фирменной айдентики O-complex.

## Правила
- Никаких лишних зависимостей, кроме shadcn/ui и lucide-react.
- Проверь в браузере (`npm run dev`) все состояния, приложи вывод или описание в ai-log.

## Готово, когда
UI работает на моке и на реальном `/api/assist`, typecheck и lint зелёные, запись добавлена в `docs/ai-log.md`.
